# 09 – ממשק ניהול

שני סוגי מנהלים:
- **מנהל/ת בית ספר (`school_admin`)** – מנהל את בית הספר שלו בלבד.
- **מנהל אלומה (`aluma_admin`)** – הצוות שלנו; גישה תפעולית בלבד, **בלי** גישה שוטפת לתוכן של תלמידים.

## ממשק מנהל בית ספר

### 1. לוח בקרה
- משתמשים פעילים (תלמידים / הורים / מורים), שאלות השבוע, הודעות שנשלחו.
- סטטוס חיבורים: ✅ תקין / ⚠️ שגיאות / ❌ מנותק, וזמן סנכרון אחרון.
- עלות AI החודש מול התקרה.
- **אין** הצגת תוכן שיחות – רק מספרים מצרפיים.

### 2. משתמשים
- ייבוא תלמידים, מורים וכיתות (CSV או מהמערכת המחוברת).
- הזמנת משתמשים, השבתה, איפוס.
- **קישורי הורה–ילד:** אישור בקשות, הפקת קודי הזמנה, חסימה (עם סיבה פנימית, לא מוצגת להורה).
- שיוך מורים לכיתות ומחנכים.

### 3. חיבורים
- חיבור Google Classroom ברמת הדומיין (אם בית הספר משתמש ב-Workspace for Education).
- חיבורים נוספים כשיהיו זמינים (05).
- כפתור **ניתוק** לכל חיבור.

### 4. מדיניות
| הגדרה | ברירת מחדל |
|--------|------------|
| פיצ'רים פעילים (ציונים / מטלות / הודעות / סיכומי כיתה למורים) | הכול פעיל מלבד סיכומי כיתה |
| הרשאות הורים (ראו 07) | ציונים, מטלות, נוכחות, מערכת |
| מגבלת הודעות למורים לתלמיד ליום | 10 |
| שעות שקט להתראות לתלמידים | 22:00–07:00 |
| שמירת היסטוריית שיחות | 90 יום |
| תקרת עלות AI חודשית | לפי חוזה |

### 5. דיווחים וחריגות
- הודעות שמורים דיווחו עליהן כפוגעניות.
- חריגות אבטחה (ניסיונות גישה חוזרים, ריבוי שגיאות הרשאה).
- בקשות פרטיות (עיון / מחיקה – ראו 17).

### 6. יומן ביקורת
- מי התחבר, מי צפה בנתוני איזה תלמיד (סוג נתון, לא תוכן), מי שינה הרשאות.
- ייצוא ל-CSV לבירורים.

### 7. עצירת חירום
- כפתור אדום: משבית את אלומה לכל בית הספר מיידית, מנתק סנכרונים. דורש אישור כפול (סיסמה + MFA).

## ממשק מנהל אלומה (פנימי)

| יכולת | הערות |
|--------|-------|
| יצירת בית ספר חדש (tenant) | כולל הגדרות ברירת מחדל |
| ניטור מערכת: זמינות, שגיאות, עלויות לכל בית ספר | ללא תוכן |
| ניהול גרסאות הנחיות AI ומודל | שינוי רק דרך תהליך שחרור (14) |
| גישת חירום לנתונים ("break glass") | רק לבירור תקלה בהסכמת בית הספר, עם תיעוד, זמן מוגבל ואישור של שני חברי צוות |

## הרשאות

- מנהל בית ספר רואה רק את בית הספר שלו (RLS לפי `tenant_id`).
- כל פעולה בממשק הניהול נרשמת ביומן הביקורת.
- MFA חובה.
