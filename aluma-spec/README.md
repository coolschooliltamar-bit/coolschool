# Aluma (אלומה) – מסמכי אפיון

> גרסה 0.1 · נובמבר 2026 · סטטוס: טיוטה לדיון
> צוות: יצחק עוז לרנר, יהושע פאס, לביא מירוני, חשן טייטלבאום

**אלומה** היא סוכנת AI שמתחברת למערכות הלימוד הקיימות (משוב, Google Classroom ועוד) ומאפשרת לתלמידים, להורים ולמורים **פשוט לשאול** – במקום לחפש בתפריטים. היא עונה על שאלות ("כמה קיבלתי במבחן בהיסטוריה?"), מסכמת ("מה יש לי השבוע?") ומנסחת הודעות למורה בסגנון של המשתמש – ושולחת אותן **רק אחרי אישור**.

## עקרונות שחוזרים בכל המסמכים

1. **לא ממציאים מידע.** כל ציון, תאריך או הודעה מגיעים ממערכת מקור, עם ציון המקור והזמן שבו נמשך.
2. **שום פעולה כלפי חוץ בלי אישור.** אלומה מנסחת – המשתמש מאשר – רק אז נשלח.
3. **כל משתמש רואה רק את המידע שמותר לו.** ההרשאות נאכפות בשרת, לא על ידי מודל ה-AI.
4. **מינימום מידע.** אוספים, שולחים ל-AI ושומרים רק את מה שצריך כדי לענות.
5. **מחליפים חיפוש, לא מערכות.** אלומה עובדת מעל המערכות הקיימות ולא מחליפה אותן.

## מוסכמות

- **"נדרש אימות"** – עובדה שלא נבדקה עד הסוף (למשל קיום API רשמי). אין להסתמך עליה לפני בדיקה.
- **"החלטה פתוחה"** – מופיעה גם ב-[OPEN_QUESTIONS](OPEN_QUESTIONS.md) עם מזהה (למשל `Q-07`).
- מסמכים טכניים מניחים **TypeScript (Node.js)** בצד השרת ו-**PostgreSQL** – ראו 01.

## מילון מונחים

| מונח | הסבר |
|------|------|
| מחבר (Connector) | רכיב שיודע לשלוף מידע ממערכת חיצונית אחת (משוב, Classroom...) |
| כלי (Tool) | פעולה מוגדרת שמנוע ה-AI יכול לבקש, למשל `get_grades` |
| פעולה ממתינה (Pending Action) | פעולה כלפי חוץ (שליחת הודעה) שמחכה לאישור המשתמש |
| דייר (Tenant) | בית ספר. כל מידע שייך לבית ספר אחד בדיוק |
| הזרקת פרומפט (Prompt Injection) | טקסט זדוני בתוך מידע (למשל בהודעה) שמנסה לגרום ל-AI לעשות משהו שלא התבקש |
